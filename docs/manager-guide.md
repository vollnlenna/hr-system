# Инструкция менеджера по персоналу

---

Добавление/изменение записей доступно на страницах:
- «Организации»
- «Отделы»
- «Должности»
- «Сотрудники»
- «Кадровые операции»

## 1. Добавление записей

Выполняется аналогично пункту 1 [Инструкции администратора](./admin-guide.md).

## 2. Изменение записей

Выполняется аналогично пункту 2 [Инструкции администратора](./admin-guide.md).

## 3. Добавление подразделения к корневому отделу структуры организации на странице «Отделы»

Выполняется аналогично пункту 4 [Инструкции администратора](./admin-guide.md).

## 4. Изменение подразделения

Выполняется аналогично пункту 5 [Инструкции администратора](./admin-guide.md).

## 5. Добавление скана паспорта сотрудника на странице «Сотрудники»

Выполняется аналогично пункту 7 [Инструкции администратора](./admin-guide.md).

## 6. Фильтрация

Выполняется аналогично пункту 11 [Инструкции администратора](./admin-guide.md).
